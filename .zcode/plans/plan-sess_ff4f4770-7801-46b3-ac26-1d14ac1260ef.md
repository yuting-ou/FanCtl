# v3.6 方案：进化传播链 + 学习图自愈确认（数据裁判轮）

## 主题

v3.5 把系统优化到位，v3.6 补两个闭环：**改进送达运行实例**（版本自检）+ **改进被数据验证**（学习图仪表化）。全程不碰控制律/安全阈值/UI 结构（球门柱），工作在 `evolution/round-2` 分支，每轮一提交，fanctltests 全绿。

## Round A（核心）：版本自检

**版本比较纯函数**（SMCCore，可测）：
- `VersionInfo` 结构：`parse("v3.6.0")` → [3,6,0]；`isNewer(_:than:)` 语义比较（逐段比，段数不齐补 0，防御 NaN/非数字段当 0）
- 落点：Config.swift 或新文件 VersionCheck.swift；测试进 TestsCore（+8~10 断言：正常/前缀 v/段数不等/相等/倒退/垃圾输入）

**更新检查器**（FanModel 内，PowerCompositionSampler 模式）：
- 启动后 60s 首查，之后每 24h 一次；`Task.detached(.utility)` + in-flight 标志 + 15s URLSession 超时
- GET `api.github.com/repos/yuting-ou/FanCtl/releases/latest`，只解 `tag_name` 一个字段的 private Codable struct
- 比较用 SMCCore 纯函数；新版本 → `@Published var updateAvailable: String?`
- UserDefaults：`updateLastCheckAt`(Date) / `updateSkippedVersion`(String)（跳过此版本后不再提示，直到更新版本）
- 失败全静默（无网/限流/超时→下次再查），绝不打扰

**UI**（最小侵入）：
- 头部"更多"Menu 顶层加一行：`Button("⬆️ 新版本 v3.6.0 可用…")` → NSWorkspace.open(releases URL)；无新版本时该行不出现
- 同位置小字"跳过此版本"Button（写入 skippedVersion）
- **不加常驻警示条**（908 固定高度余量仅 4.5pt，反经验）

## Round B：学习图包络健康仪表化

- status.json 新增可选字段 `learnEnvelopeHealth: Double?`（decodeIfPresent，向后兼容）：`monotonicEnvelope(88°桶) − rawEMA(88°桶)` 的差值；差值大=旧非单调数据尚未被新样本洗净
- fanprobe 打印该值；EVOLUTION.md 记录观察协议：2-3 周后差值应收敛→闭环确认；不收敛（88° 无稳态样本）→ 下轮做一次性数据修正（非单调桶重置，学习数据修正不碰控制律）

## Round C：版本发布

- VERSION → `3.6.0 52`；README 变更摘要；tag v3.6.0 → CI 自动打 Release zip（验证 4A 链路二连跑）

## 验证闸门（每轮）

fanctltests 全绿（断言数只增）/ 族扫描 0 违例 / 快照版式复核（Menu 加行不破 908 契约）/ 真机部署后查新功能实际行为（本机可验：改 VERSION 文件造一个假高版本观察提示出现）。

## 明确不做

控制律/τ/过冲（硬件边界）、NN/负载预测、UI 结构重设计、自动安装更新（常驻不添乱原则——只提示不代装）。
